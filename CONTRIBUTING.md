# CONTRIBUTING.md

Спасибо за интерес к участию в разработке **VS IMPOSTOR Pixel**! Ниже приведены рекомендации, которые помогут вам внести свой вклад в проект.

## Как внести свой вклад

### 1. Сообщение об ошибках (Issues)

Если вы обнаружили ошибку или у вас есть предложение по улучшению, пожалуйста:

- Проверьте существующие issues, чтобы убедиться, что проблема ещё не была описана
- Создайте новый issue с подробным описанием:
  - Шаги для воспроизведения ошибки
  - Ожидаемое и фактическое поведение
  - Версия игры и платформа (Windows, Android, etc.)
  - Скриншоты или логи (если применимо)

### 2. Предложения по улучшению (Pull Requests)

Мы приветствуем ваши pull requests! Пожалуйста, следуйте этим шагам:

#### Перед началом работы

1. **Форкните репозиторий** и создайте новую ветку от `main`
2. **Обсудите изменения**: для крупных изменений сначала создайте issue для обсуждения
3. **Установите зависимости**: убедитесь, что у вас установлены все необходимые библиотеки Haxe/Flixel

#### Требования к коду

- Следуйте существующему стилю кода в проекте
- Используйте `hxformat.json` для автоматического форматирования кода
- Добавляйте комментарии к сложным участкам кода
- Убедитесь, что ваш код компилируется без ошибок

#### Тестирование

Перед отправкой PR:

- Протестируйте изменения на всех поддерживаемых платформах (Desktop, Mobile)
- Убедитесь, что новые функции работают корректно
- Проверьте, что существующий функционал не сломан

#### Отправка PR

1. Дайте понятное название вашему pull request
2. Опишите изменения в description
3. Свяжите с соответствующими issue (если есть)
4. Дождитесь ревью от мейнтейнеров

## Структура проекта

```
VS-IMPOSTOR-Pixel/
├── source/                 # Исходный код на Haxe
│   ├── Main.hx            # Точка входа
│   └── impostor/          # Основные модули игры
│       ├── api/           # API интеграции (Discord и др.)
│       ├── play/          # Игровой процесс
│       ├── sound/         # Звуковая система
│       ├── system/        # Системные компоненты
│       └── ui/            # Пользовательский интерфейс
├── assets/                # Ресурсы игры (музыка, изображения)
├── .artwork/              # Арт-ресурсы и иконки
├── project.hxp            # Конфигурация проекта Lime/OpenFL
└── hxformat.json          # Настройки форматирования кода
```

## Технологический стек

- **Язык**: Haxe
- **Фреймворк**: Flixel
- **Движок**: Codename Engine (на базе Lime/OpenFL)
- **Платформы**: Windows, Linux, macOS, Android, iOS, HTML5

## Лицензия

Внося изменения в этот проект, вы соглашаетесь с тем, что ваш код будет распространяться под той же лицензией, что и проект (см. [LICENSE](LICENSE)).

## Вопросы?

Если у вас возникли вопросы, не стесняйтесь задать их в Discord-сообществе или создать issue в этом репозитории.
